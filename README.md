# 🏎️ LAP44 – Web3 Racing Platform

### Race. Compete. Earn.

LAP44 is a blockchain-powered competitive racing platform that combines immersive 3D gameplay with decentralized technology. Players can connect their crypto wallets, participate in stake-based races, and compete in a transparent environment secured by smart contracts.

The platform leverages Web3 technologies to create trustless gameplay mechanics while delivering an engaging racing experience through interactive 3D environments built with React Three Fiber.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/lap44-web3-racing.git
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

```env
NEXT_PUBLIC_RPC_URL=
NEXT_PUBLIC_CONTRACT_ADDRESS=
NEXT_PUBLIC_CHAIN_ID=
```

### Run Development Server

```bash
npm run dev
```
